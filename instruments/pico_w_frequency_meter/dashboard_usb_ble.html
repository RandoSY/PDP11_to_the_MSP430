Command Reference

Core: IDN?, STATUS?, MEASURE, PING, HELP

Streaming: STREAM ON, STREAM OFF, SET STREAM_MS 1000

Meter: SET GATE 250, SET SAMPLES 3, SET PIN_IN 14

Generator: GEN SET 1000 50, GEN ON, GEN OFF, SET PIN_OUT 15

Config: SAVE, FACTORY
